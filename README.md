# 四象限

一款轻量的 macOS 桌面事项管理工具，用四象限梳理优先级，并提供独立的 To Do List 临时收集区。

界面采用苹果极简风格和莫兰迪配色，窗口可自由缩放，适合常驻桌面使用。

## 功能介绍

- 四象限管理：重要且紧急、重要不紧急、紧急不重要、不重要不紧急。
- 独立 To Do List：先快速记录，再拖入合适的象限。
- 跨区域拖拽：任意事项可在四个象限和 To Do List 之间移动。
- 新增与修改：点击 `+` 新增事项，双击文字修改。
- 完成即隐藏：点击事项左侧圆圈，完成后自动从当前列表隐藏。
- 自由调整布局：窗口可缩放，四象限内部横向、纵向边界均可拖动。
- 菜单栏收起：点击左上角 `−`，应用会收起到菜单栏。
- 临时置顶：需要时点击图钉，取消后恢复普通窗口层级。
- 本地自动保存：事项和分界位置会自动保存在当前 Mac。
- 通用架构：同时支持 Apple 芯片和 Intel 芯片 Mac。

## 系统要求

- macOS 14 或更高版本
- Apple 芯片或 Intel 芯片 Mac

## 安装方法

1. 打开右侧的 [Releases](../../releases) 页面。
2. 下载最新版 `四象限-1.8.0-通用版.dmg`。
3. 双击 DMG，把「四象限」拖进 `Applications（应用程序）`。
4. 前往“应用程序”，打开「四象限」。

## 首次打开提示

当前版本尚未经过 Apple 开发者公证。macOS 首次打开时可能显示安全提醒：

1. 在“应用程序”中右键「四象限」，选择“打开”。
2. 在弹窗中再次选择“打开”。
3. 如果仍被阻止，前往“系统设置 → 隐私与安全性”，找到「四象限」并选择“仍要打开”。

这是 macOS 对未公证应用的常规限制，并不代表安装包损坏。

## 数据与隐私

- 所有事项仅保存在当前 Mac 本地。
- 应用不会要求注册账号，也不会把事项上传到网络。
- 关闭、升级或重新打开应用不会清空事项。
- 不同电脑之间暂不支持自动同步。
- 卸载应用前，如需保留事项，请先不要清理应用偏好设置。

## 使用方法

- 新增事项：点击区域右上角 `+`，输入后按回车。
- 修改事项：双击事项文字，修改后按回车。
- 完成事项：点击事项左侧圆圈，事项会立即隐藏。
- 移动事项：按住事项并拖到其他象限或 To Do List。
- 调整象限：拖动象限之间的白色分界线或中心圆点。
- 收起窗口：点击左上角 `−`，再从菜单栏图标打开。
